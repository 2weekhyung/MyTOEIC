# MyTOEIC 학습 웹사이트 0.3.0

## 현재 배포 상태 · 2026-11-01

Linux 앱·Nginx·도메인·HTTPS 배포와 첫 사이트 계정 생성을 완료했다. 사용자가 HTTPS health UP과 인증서 갱신 모의 실행 성공을 확인했다. 실제 앱은 Docker 네트워크의 전용 런타임 계정을 사용하며 PC용 런타임 계정은 로컬 개발 시에만 별도로 필요하다. 상세 상태와 운영 점검은 [배포 안내](DEPLOYMENT.md)를 참고한다. 아래 로컬 실행과 화면 검증 기록은 배포 이전에 수행한 작업을 포함한다. 운영 DB V5 적용은 계속 보류한다.

## 사용할 수 있는 화면

React·TypeScript·Vite·Tailwind로 구현하고 Spring Boot의 실제 세션 인증 및 학습 API에 연결했다. 화면용 가짜 학습 데이터나 브라우저에만 남는 학습 기록을 사용하지 않는다.

- 공부방: 실제 하루 목표 달성률, 오늘·주간 학습량, 연속 학습일, 다음 강의, 복습 목록과 규칙 기반 추천.
- 문법: 첫 10강의 한국어 본문, 쉬운 재설명, 번역된 예문, 색상과 텍스트를 함께 쓰는 성분 분석, 핵심 정리, 확인 문제, 진도 저장, 다음 강의.
- RC: Part 5 문항 수·순서 선택, 유형별 집중 연습, Part 6 전체 지문과 4문항, Part 7 단일·이중·삼중 지문. 제출 후 전체 문장 번역·정답·4개 선택지 해설과 지문 번역을 확인.
- 단어: 200개 전체 검색·레벨 필터, 개인 저장, 기억한 단어 목록, 5/10/20개 카드 학습, 4지선다 뜻 맞히기, 기억 여부 저장과 간격 복습.
- 오답·복습: 자동 오답 저장, 해결 여부, 누적 오답 횟수, 재풀이, 관련 기초 강의. 다시 맞혀도 과거 이력 보존.
- 통계: 7/30/90일 실제 학습 시간, 유형별 정답률, 파트별 기록, 풀이 당시의 해설 이력.
- 설정: 목표 600/700/800 또는 직접 입력, 하루 시간, 시간대, 목표 이력, 다크모드, 로그아웃.
- 기초 진단: 10문항, 중간 새로고침 시 이어풀기, 유형별 진단과 연결 강의. 공식 점수 예측은 표시하지 않음.

아이폰용 하단 메뉴·안전 영역·터치 버튼·가로 넘침 방지를 적용했다. PWA manifest와 PNG 아이콘, service worker 및 오프라인 안내를 포함한다. 학습 API·로그인·정답·개인 데이터는 service worker에 캐시하지 않는다. 홈 화면 설치에는 HTTPS가 필요하며 아이폰 Safari의 공유 메뉴를 사용한다.

## 서버 DB에 연결해 로컬에서 사용

현재 실제 서버는 V4다. 2026-11-01 사용자가 V5 내용 보완은 코드에만 준비하고 서버 적용을 보류하도록 지정했다. 앱 기동 시 Flyway는 비활성화되어 있다. 별도 승인 없이 `dbMigrate`나 `--migrate-only`를 실행하지 않는다.

실제 사용 전에는 DB 관리자가 앱 실행용 `mytoeic_app` 계정을 PC 접속 IP에 맞게 생성하고 `infra/mysql/runtime-grants.sql`의 최소 권한을 적용해야 한다. 기본 개인 YAML의 datasource는 그 앱 계정으로 지정한다. migration 계정은 Spring Flyway의 user/password에만 둔다. 실제 개인 YAML은 Git·배포 JAR·Docker 빌드에서 제외한다.

프로젝트 루트의 PowerShell에서:

```powershell
.\scripts\start-study.ps1
```

스크립트는 프론트 빌드를 수행하고 Java 17로 백엔드를 loopback의 `http://localhost:8081`에서 실행한다. 프로세스가 실행된 동안만 유효한 무작위 설치 토큰을 만들고 개인 계정 설정 링크를 `private/study-access.html`에 기록한다. 로그에 Started가 나온 뒤 그 파일의 링크를 열어 아이디와 비밀번호(16자 이상·UTF-8 72바이트 이하)를 직접 정한다. 비밀번호를 채팅·로그·Git에 남길 필요가 없다. 이 링크는 공유하지 않는다.

회원가입은 없다. 첫 계정이 만들어지면 설치 API는 다시 사용할 수 없고, 기존 비밀번호를 초기화하지 않는다. 설치 토큰은 프론트 번들에 포함하지 않으며, URL fragment에서 읽은 뒤 주소창에서 제거한다. 상태 변경에는 설치 요청까지 포함해 CSRF 토큰이 필요하다.

최초 설정 후에는 일반 주소 `http://localhost:8081`로 로그인한다. 스크립트를 다시 실행해도 기존 계정과 학습 기록은 남는다. 앱을 종료하면 메모리 세션은 만료되므로 다시 로그인해야 한다.

## 서버를 변경하지 않고 화면 검증

```powershell
cd frontend
npm ci
npm run build
cd ../backend
.\gradlew.bat webTestRun
```

`http://localhost:18081`, 테스트 아이디 `learner`, 테스트 비밀번호 `test-only-LongPassword!27`이다. 이 공개 테스트 계정은 격리된 H2 메모리 DB에만 만들어진다. 실제 서버 DB 설정은 사용하지 않는다. 브라우저 상단에 테스트 모드를 표시하며 앱 프로세스를 종료하면 기록은 사라진다. 영구 학습용으로 이 모드를 사용하지 않는다.

## 개발과 패키징

프론트 단독 개발은 `frontend`에서 `npm run dev`를 실행한다. Vite는 5173 포트의 같은 출처 `/api` 요청을 8081 백엔드로 프록시한다. 프론트 번들에 DB 주소·계정·비밀번호를 넣지 않는다.

```powershell
cd frontend
npm test
npm run build
cd ../backend
.\gradlew.bat test mysqlTest bootJar
```

`mysqlTest`에는 Docker가 필요하고 일회용 테스트 DB만 사용한다. 배포 JAR는 `backend/build/libs/mytoeic-0.3.0.jar`이며 React 빌드를 함께 담는다. 프론트 빌드가 없으면 패키징을 중단한다. 기존 개인 접속정보 대신 `application.yml.example`이 JAR에 들어가므로 배포할 때 별도의 비공개 설정을 제공한다.

Docker 빌드는 저장소 루트가 context다. `docker build -f backend/Dockerfile -t mytoeic:0.3.0 .` 또는 기존 Compose 파일을 사용한다. Node 빌드 단계와 Java 빌드 단계로 나누고 실제 DB를 새로 만들지 않는 배포에는 `compose.existing-db.yml`을 사용한다. Nginx 템플릿은 정적 화면과 API를 같은 출처로 프록시한다. 실제 서버는 검증한 JAR를 읽기 전용 마운트한 컨테이너로 배포했다.

마지막 화면 스타일 보정은 소스와 `frontend/dist` 빌드까지 완료했다. 그 보정 후의 최종 JAR 재빌드 명령은 실행 승인이 거절되어 실행하지 않았다. 현재 0.3.0 JAR는 직전에 검증한 빌드이며, 이후 실제 배포 전에 위 패키징 명령을 다시 실행해 마지막 스타일 보정을 포함해야 한다.

격리된 테스트 계정으로 로그인, 강의 재설명, 두 확인 문제, 진도 100%, 북마크, 오답 자동 저장, 단어 검색·저장·카드 암기·뜻 맞히기·기억한 목록, Part 6 제출 후 번역, Part 7 삼중 지문, 진단 새로고침 이어풀기·10문항 결과, 목표 변경과 공부방 반영, 통계 표시를 실제 브라우저에서 확인했다. 아이폰 크기와 PC 크기에서 DOM의 가로 넘침을 확인했다. 실제 아이폰 Safari 기기와 공인 HTTPS 배포 환경은 아직 검증하지 않았다.
