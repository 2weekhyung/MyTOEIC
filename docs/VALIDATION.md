사용자가 실제 서버에서 HTTPS `/api/health`의 UP 응답, Certbot 갱신 모의 실행 성공, 앱 재시작 정책, Docker·Nginx·Certbot timer·HTTPS 방화벽 서비스 enabled 상태를 확인했고 첫 계정을 생성했다. 아래의 브라우저 QA는 격리된 H2에서 수행한 기록이다. 실제 iPhone Safari 하드웨어 검증과 서버 재부팅 시험을 수행했다는 의미는 아니다. [배포 기록](DEPLOYMENT.md)을 참고한다.

## 검증한 동작

- V1~V4 마이그레이션, Hibernate `validate`, InnoDB 명시.
- 강의 10·예문 30·연습 20·Part 5 50·Part 6 16·Part 7 30·단어 200·정답 116·선택지 464.
- RC 세트 12·지문 16, Part 6 빈칸 4개와 Part 7 단일/이중/삼중 지문 구성.
- 시드 SQL을 두 번 더 실행해도 콘텐츠 수와 기존 학습 이력·오답이 유지됨.
- 동일 제출 키 재시도, 다른 내용의 키 재사용 거부, 동시 재전송에도 기록/통계 1개.
- 오답 후 정답을 맞혀도 최초 오답과 모든 풀이 이력 유지.
- 이후 문항 본문을 수정해도 제출 당시 스냅샷 유지.
- 다른 문제의 선택지 거부와 전체 트랜잭션 롤백, 복합 FK에 의한 정답 관계 강제.
- 복습 일정의 단일 대상 CHECK, 진도 비감소, 단어장 중복 방지, 암기·복습 일정 갱신.
- 진단 미완료 종료 거부, 완료 결과 보존, 새 회차 시작, 다른 사용자 기록 접근 차단.
- 목표 변경 이력 유지와 시간대 검증.
- 학습 통계 읽기 전용 감사 SQL: 정상 일치, 의도적인 불일치 탐지.
- 20문항 페이지 조회 쿼리 수 상한(4회 이하), EntityGraph·배치 선택지 조회.
- 미인증 401, CSRF 누락 403, 잘못된 입력/페이지 크기 400, 일반 문제 응답에 정답·선택지 해설 없음.
- 실제 폼 로그인·새 CSRF 토큰·세션 인증·로그아웃 무효화.
- 별도 앱 계정으로 학습 저장 성공. 테이블 생성·학습 원본 DELETE·강의 UPDATE 권한 거부.
- 최소 권한 migrator로 별도 신규 DB에 설치 및 재실행.
- 저장소의 백업/복원 스크립트를 컨테이너 안에서 실제 실행: mysqldump→gzip→체크섬→새 DB 복원, 콘텐츠·계정·Flyway 이력 확인, 이미 있는 복원 대상 거부.
- V4 시드를 두 번 더 실행해도 지문·문항·선택지·풀이 이력이 중복되지 않음.
- Part 6·7 문제 조회에 영어 지문 제공, 제출 전에 지문 번역·정답·해설 미노출.
- 제출한 삼중 지문 전체·번역을 스냅샷으로 보존하고 이후 본문 수정에도 과거 이력 유지.
- RC에서도 기존 오답노트·북마크·재시도·사용자별 파트 통계를 재사용.
- Part 7 20문항 페이지 SQL 6회 이하, 지문 세트 목록 4회 이하.
- 실제 최소 권한 앱 계정으로 RC 조회·채점 저장 성공.
- V2까지만 설치한 별도 MySQL DB에 진도·강의 이벤트·단어 암기·오답·풀이·일별 통계를 만든 뒤 V3/V4로 업그레이드. 기존 원본 행 불변, 구형 JSON 스냅샷 조회, 기존 통계 보존, 새 RC 풀이 저장을 검증.
- 실제 0.2.0 JAR를 별도 Java 17 컨테이너에서 `java -Xmx256m -jar /app.jar --migrate-only`로 실행. 최소 권한 설치 계정으로 V1~V4 성공과 문제 116개·지문 16개 설치를 확인.
- 읽기 전용 연결 확인: SELECT 권한만 가진 계정으로 비어 있는 전용 DB를 조회해도 테이블·Flyway 이력이 생성되지 않음. 설치된 DB에서는 기존 V4와 테이블 27개(업무 26+Flyway 1)를 읽음. 로컬 실행 스크립트의 PowerShell 문법 검사도 통과.
- 직접 연결 YAML에서 서버 URL을 그대로 읽고 앱/설치 비밀번호를 분리하는 테스트 통과. 실제 로컬 서버 설정 파일은 Git과 Docker 빌드에서 제외되며 JAR에 포함되지 않음을 확인.

## 0.2.0 검증 당시 남아 있던 범위

로컬 YAML의 실제 서버 주소와 설치 계정으로 직접 JDBC 연결을 시도했으나 TCP 연결 시간 초과로 인증 단계에 도달하지 못했다. 로컬 자동 테스트 통과를 실서버 연결 성공으로 표시하지 않는다. 서버 네트워크/접속 허용 상태를 확인해야 하며 실제 테이블·데이터 변경은 하지 않았다.

Codex가 개인 Linux 서버에 직접 접속하거나 RC 변경을 적용하지 않았다. 사용자가 별도 서버에서 MySQL 8.0.46 확인·전용 DB/계정 생성·설치 계정 접속 테스트를 완료했다고 전달했다. 서버의 테이블 설치 완료는 확인되지 않았다. GitHub push·Nginx/HTTPS 실제 적용은 하지 않았다. 로컬 테스트가 만든 DB·계정·복원본은 일회용 컨테이너 내부에만 존재했다.

React 모바일 UI·PWA·Safari 사용성, 실제 서버의 방화벽/TLS/성능, 오프사이트 백업 작업, 독립된 영어 교육 전문가의 콘텐츠 감수는 이후 검증 대상이다. 이번 테스트 결과를 개인 서버 연동 완료나 전체 웹사이트 완성으로 간주하지 않는다.
